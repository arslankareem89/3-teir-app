# 3-Tier AWS ECS Application

Hands-on AWS DevOps learning project.

## Stack

* AWS ECS
* Fargate
* EC2
* ECR
* ALB
* RDS PostgreSQL
* Cloud Map
* Service Connect
* Terraform
* Docker

## Architecture

Frontend → Backend → PostgreSQL

## Region

`ap-south-1`

## Goal

Build and deploy a 3-tier application on AWS while learning ECS, Fargate, EC2, Terraform, networking, security, and CI/CD.
